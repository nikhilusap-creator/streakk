# Streakk Stock Monitor

A personal PWA for tracking stock price momentum streaks, RSI signals, and volume context.

## Features
- Consecutive up/down streak tracking
- RSI overbought/oversold signals
- Volume context (above/below average)
- 52-week high/low proximity indicator
- Multi-timeframe charts (1D, 1W, 1M, 3M, 1Y, 5Y)
- Intraday reversal detection
- Configurable streak history (10/20/30/50 days)
- Installable PWA — works on iPhone and Android
